# CA 자료 폴더

이 폴더에 아래 파일을 **정확한 이름**으로 올리면 `index.html`은 고칠 필요가 없습니다. 파일 이름의 숫자는 CA 순서입니다.

지금 ZIP의 `ca1_photo.png`~`ca5_photo.png`는 실제 CA가 아닌 **예시 가상 인물**이며, 링크 파일 7개에는 테스트용으로 `https://chatgpt.com/`이 들어 있습니다. 운영 전 교체하세요.

| 순서 | CA | 사진 파일 | 개인 상담 링크 파일 |
| --- | --- | --- | --- |
| ca1 | 정예진 · 꼼꼼한 취향파 | `ca1_photo.jpg` | `ca1_link.txt` |
| ca2 | 강지형 · 자유로운 탐험가 | `ca2_photo.jpg` | `ca2_link.txt` |
| ca3 | 이준혁 · 조용한 실행파 | `ca3_photo.jpg` | `ca3_link.txt` |
| ca4 | 윤서아 · 활기찬 에너지파 | `ca4_photo.jpg` | `ca4_link.txt` |
| ca5 | 이승민 · 만능 올라운더 | `ca5_photo.jpg` | `ca5_link.txt` |

공통 단체방은 **`ca_chat_link.txt`** 파일 하나로 관리합니다.

결과 화면의 피자파티 수요조사 링크는 **`pizza_party_link.txt`**에서 관리합니다. 실제 구글폼 URL 한 줄로 교체하세요. 링크 파일을 삭제하면 행사 링크는 결과 화면에 나타나지 않습니다.

개별 CA 프로필의 전공·관심사·MBTI와 결과 화면의 아이콘은 다음 파일로 관리합니다. CA 번호만 바꿔서 각자 수정하면 됩니다.

| 항목 | 예시 파일 | 입력 내용 |
| --- | --- | --- |
| 전공 | `ca1_major.txt` | 실제 전공 한 줄 |
| 관심사 | `ca1_interest.txt` | 관심사 한 줄 |
| MBTI | `ca1_mbti.txt` | 본인이 공개에 동의한 유형 한 줄. 원하지 않으면 `비공개` |
| 결과 아이콘 | `ca1_icon.txt` | 이모지 하나. 예: `🎨` |

지금은 전공·관심사·MBTI 모두 예시 문구라서 실제 CA 정보로 오해하지 않도록 배포 전에 고쳐주세요. MBTI를 공개하지 않을 때도 HTML은 편집할 필요 없이 `.txt`에 `비공개`라고 쓰면 됩니다.

- 사진은 `.jpg`가 우선이며, 없으면 `.png`, `.webp` 순으로 찾습니다. 이름은 `ca1_photo.png`처럼 번호와 `_photo`를 그대로 씁니다. 사진은 결과 화면·전체 CA 목록·개별 프로필에 동일하게 사용됩니다.
- 링크 파일은 텍스트 파일(`.txt`)로 만들고 내용에는 `https://open.kakao.com/o/실제주소`처럼 **URL 한 줄만** 입력합니다. `ca1_link`처럼 `.txt` 없이 올려도 읽지만 `.txt`가 관리하기 편합니다. 따옴표, `링크:`, 공백, 다른 문장은 넣지 마세요.
- 파일이 없으면 사진은 이름 카드로 대체되고 링크 버튼은 비활성화됩니다. 새 파일을 업로드하거나 기존 파일을 교체해 Commit한 뒤 몇 분 후 사이트를 새로고침하세요.
- GitHub 웹페이지에서 `.txt` 파일을 클릭해 내용을 보는 화면은 사이트가 아닙니다. 실제 동작은 Pages URL에서 확인하세요.
- 이 폴더의 자료는 공개됩니다. CA의 사진 공개 동의와 오픈채팅 초대 링크의 공개 범위를 먼저 확인하세요.
