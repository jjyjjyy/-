# CA 성향 테스트 — GitHub Pages 업로드

웹페이지는 `index.html`이고 사진·오픈채팅 주소는 **`ca-assets` 폴더의 파일**만 바꾸면 됩니다. HTML 수정은 필요하지 않습니다.

## 업로드

1. ZIP을 풀고 `index.html`, `README.md`, `ca-assets` 폴더를 GitHub 레포 **최상위**에 올립니다. ZIP 바깥의 `ca-test` 폴더째 올리면 안 됩니다.
2. GitHub 레포에서 **Settings → Pages → Deploy from a branch → main / (root) → Save**를 선택합니다.
3. Pages에 표시되는 사이트 주소(`https://계정.github.io/레포이름/`)로 접속합니다. GitHub의 파일 보기 주소에서는 HTML 코드가 보이는 게 정상입니다.

## 사진과 상담 링크 관리

정확한 파일명과 넣는 방법은 [`ca-assets/README.md`](ca-assets/README.md)에 있습니다. `ca1`부터 `ca5`까지는 정예진, 강지형, 이준혁, 윤서아, 이승민 순서입니다. 사진은 `ca1_photo.jpg`(또는 `.png` / `.webp`), 상담 주소는 `ca1_link.txt` 형식이며, 공통 단체방은 `ca_chat_link.txt`입니다. 링크 파일에는 `https://`로 시작하는 URL **한 줄만** 넣으세요.

링크 파일이 없거나 URL 형식이 잘못되면 해당 버튼은 비활성화됩니다. 사진이 없거나 이름이 틀리면 이름 두 글자 카드가 대신 나타납니다. GitHub Pages 파일명은 대소문자를 구분합니다. 기존 `images` 폴더와 이전 HTML의 링크 설정은 더 이상 사용하지 않습니다.

현재 ZIP에는 **가상의 인물 일러스트** 5장, CA 프로필 텍스트 자리표시자, `https://chatgpt.com/`을 적은 상담·단체방·피자파티 예시 링크 파일 7개가 포함되어 있습니다. 사진과 프로필은 실제 CA 정보가 아닙니다. 모든 링크가 현재는 ChatGPT로 이동하므로 배포 전 실제 오픈채팅 주소와 피자파티 구글폼 URL로 교체하세요.

상담 안내 문구는 **테스트 결과 화면에만** 나옵니다. 개별 CA 프로필에서는 결과 분석·상담 안내 대신 사진과 전공·관심사·MBTI를 보여줍니다. 전체 목록은 사진 왼쪽, 유형과 CA 이름 오른쪽의 가로 목록입니다.

## 판정 규칙

Q1 문화·예술 → Q2 계획/즉흥에 따라 CA1/CA2. Q1 운동 → Q3 혼자·소수/여럿에 따라 CA3/CA4. Q1 둘 다 → CA5. 모든 사용자는 세 질문에 답합니다.

공개 레포와 Pages에는 사진·채팅 주소가 공개됩니다. 사진 공개 동의를 받고, 외부인에게 공개해도 되는 채팅 링크만 사용하세요. 응답은 저장하지 않습니다.
